# Currículo online

Meu currículo em página web, publicado no GitHub Pages:
**https://kauan-v-marques.github.io/curriculo/**

- Português e inglês, com botão para trocar o idioma (ou direto pelo link com `?lang=en`)
- Layout responsivo, que funciona bem no celular
- Botão "Salvar PDF", que gera a versão para impressão em A4
- Tema claro e escuro, seguindo a configuração do sistema

Feito só com HTML, CSS e um pouco de JavaScript, sem framework.

Para ver localmente, basta abrir o `index.html` no navegador.
